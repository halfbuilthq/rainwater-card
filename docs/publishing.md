1. Confirm CI and HACS validation pass on `main` without ignored checks.
2. Publish a full GitHub release containing `rainwater-card.js`.
3. Install the release as a custom HACS **Dashboard** repository and verify it.

   branch of a personal fork of `hacs/default`.
