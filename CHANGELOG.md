# Changelog

All notable changes to this project are documented here. The project follows
Semantic Versioning.

## [Unreleased]

## [0.1.3] - 2026-11-01

### Fixed

- Keep the tank summary inside its panel near the compact layout breakpoint.
- Truncate long card titles within their available space so they cannot cover the status badge.

## [0.1.2] - 2026-09-02

### Added

- Mouse, touch, and keyboard inspection for stored-water history.
- Point-in-time tooltips and accessible chart navigation.

### Changed

- Standardized card, chart, and tooltip backgrounds on Home Assistant's
  current theme variables with legacy fallbacks.
- Clear chart inspection when a touch gesture is cancelled by scrolling.

## [0.1.1] - 2026-09-02

### Added

- HACS Default catalogue information and publishing guidance.
- Repository security policy and dependency maintenance configuration.

## [0.1.0] - 2026-07-29

- Initial public release of the Rainwater Card.
